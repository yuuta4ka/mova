# Mova UI-kit

Рабочий локальный MVP мессенджера Mova в тёмном стиле Liquid Glass.

Реализованы регистрация и вход, личные и групповые чаты, постоянное хранение сообщений, синхронизация через WebSocket и голосовые звонки через WebRTC.

## Запуск

Требуются Node.js и pnpm.

```bash
pnpm install
pnpm dev
```

Одна команда запускает frontend и локальный API. Приложение откроется на `http://127.0.0.1:5173`, API — на `http://127.0.0.1:8787`.

Данные сохраняются локально в `.mova-data/db.json` и не попадают в Git. Для проверки общения между двумя пользователями откройте Mova в двух вкладках и зарегистрируйте разные аккаунты: сессии хранятся отдельно для каждой вкладки.

Во время первого голосового звонка браузер запросит доступ к микрофону. Для связи за пределами локальной сети потребуется HTTPS и production TURN-сервер.

## Storybook

```bash
pnpm storybook
```

Storybook содержит состояния примитивов, продуктовые компоненты и полноэкранный сценарий чата.

## Проверки

```bash
pnpm test
pnpm build
pnpm build-storybook
```

Публичные компоненты, токены и демонстрационные модели экспортируются из `src/index.ts`.

## Публикация на Amvera

В репозитории уже находятся `Dockerfile` и `amvera.yaml`. При запуске в Amvera
приложение использует публичный порт `80`, а база сохраняется в постоянном файле
`/data/db.json`.

1. Создайте в Amvera новое приложение и загрузите в него этот Git-репозиторий.
2. В разделе «Переменные» добавьте **секрет** `MOVA_SESSION_SECRET` со случайным
   длинным значением (не менее 32 символов).
3. Запустите сборку, затем приложение.
4. В настройках сети добавьте бесплатный домен Amvera с типом подключения HTTPS
   и портом `80`.
5. Проверьте `https://<ваш-домен>/api/health`, затем откройте сам домен.

Для локальной проверки production-режима:

```bash
pnpm build
MOVA_SESSION_SECRET=local-production-check pnpm start
```
